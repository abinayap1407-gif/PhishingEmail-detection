Phishing Email Detection Model

📌 Project Description

The Phishing Email Detection Model is a Machine Learning project developed using Python and Scikit-learn. It identifies whether an email is Phishing or Safe by analyzing its textual content, keywords, and URL features.

🎯 Objectives

- Detect phishing emails.
- Identify suspicious keywords and URLs.
- Classify emails as Phishing or Safe.
- Improve email security through Machine Learning.

✨ Key Features

- Training with phishing and legitimate email samples.
- Email feature extraction.
- Automatic email classification.
- Accuracy calculation.
- Confusion Matrix generation.
- Classification Report.
- User input for testing emails.

🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- Machine Learning

⚙️ How to Run the Project

1. Install Python.

2. Install the required libraries.

3. Open the project folder in VS Code.

4. Run the following command:
   
   "python phishing_detector.py"

5. Enter an email message.

6. View the prediction result.

📊 Model Evaluation

The model displays:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

📌 Expected Output

The system classifies the entered email into one of two categories:

- Phishing Email
- Safe Email
